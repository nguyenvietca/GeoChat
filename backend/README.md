# GeoChat Backend

This is the backend skeleton for the GeoChat modular monolith.

## Stack

- Java 21
- Spring Boot 4.1.x
- PostgreSQL + PostGIS
- Spring Security + JWT
- Spring WebSocket
- Flyway migrations

## Run locally

```bash
./mvnw spring-boot:run
```

## Notes

This is a skeleton only. Business logic and domain features will be added in later phases.
